# Исправления ошибок

## Проблемы, которые были исправлены:

### 1. Ошибка 404 для CSS/JS файлов
**Проблема:** Файлы `owl.carousel.min.css`, `owl.carousel.min.js` и `home.min.js` не существовали.

**Решение:**
- Использован CDN для Owl Carousel (https://cdnjs.cloudflare.com/ajax/libs/OwlCarousel2/2.3.4/)
- Скопирован файл `home.min.js` из оригинального сайта
- Добавлена проверка существования файла перед загрузкой

### 2. Ошибка MIME type
**Проблема:** Браузер получал HTML вместо CSS/JS (404 ошибка возвращала HTML страницу).

**Решение:**
- Исправлены пути к файлам
- Использован CDN для отсутствующих файлов
- Добавлена проверка существования файлов перед загрузкой

### 3. Ошибка "landing is not defined"
**Проблема:** В `main.min.js` использовался объект `landing`, который не был определен (код для интеграции с Creatio CRM).

**Решение:**
- Добавлены проверки `typeof landing !== 'undefined'` во все функции, использующие `landing`
- Функции теперь не вызываются, если объект не определен

## Измененные файлы:

1. `functions.php` - исправлена загрузка скриптов и стилей
2. `main.min.js` - добавлены проверки для объекта `landing`
3. `front-page.php` - добавлена инициализация слайдера

1. Очистите кеш браузера (Ctrl+F5)
2. Проверьте права доступа к файлам
3. Убедитесь, что тема активирована
4. Проверьте консоль браузера на наличие других ошибок
