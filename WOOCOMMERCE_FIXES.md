# Исправления шаблонов категорий товаров

## Проблема
На странице категории товаров `http://localhost/product-category/borony/` ничего не выводилось.

## Выполненные исправления

### 1. Исправлена логика вывода в `taxonomy-product_category.php`

**Было:**
- Шаблон показывал и подкатегории, и товары одновременно
- Не было четкого разделения между родительскими и дочерними категориями

**Стало:**
- **Если категория верхнего уровня (parent == 0) И есть подкатегории** → показываются только подкатегории
- **Если категория верхнего уровня, но НЕТ подкатегорий** → показываются товары
- **Если категория вложенная (parent != 0)** → показываются товары

### 2. Улучшен хук `pre_get_posts` в `functions.php`

**Изменения:**
- Добавлена проверка `is_main_query()` для избежания конфликтов
- Установка `post_status = 'publish'` для показа только опубликованных товаров
- Улучшена обработка запроса для таксономии `product_category`

### 3. Создан файл `taxonomy-product_cat.php`

Для совместимости с WooCommerce (если используется таксономия `product_cat`). Файл перенаправляет на основной шаблон `taxonomy-product_category.php`.

### 4. Создан файл `woocommerce/content-product.php`

Для совместимости со стандартной структурой WooCommerce. Использует шаблон из `template-parts/content-product.php`.

### 5. Добавлена функция обновления счетчиков категорий

Функция `texk_update_product_category_counts()` для ручного обновления счетчиков товаров в категориях (закомментирована, можно вызывать при необходимости).

## Логика работы шаблона

### Родительская категория (parent == 0)
1. Проверяются подкатегории
2. Если есть подкатегории → показываются только они
3. Если нет подкатегорий → показываются товары из этой категории

### Дочерняя категория (parent != 0)
1. Показываются только товары из этой категории
2. Подкатегории не проверяются

   ```php

   ```

3. **Очистите кеш:**
   - Очистите кеш WordPress (если используется плагин кеширования)
   - Обновите постоянные ссылки: Настройки → Постоянные ссылки → Сохранить

4. **Проверьте запрос:**

### Если подкатегории не отображаются:

1. **Проверьте иерархию категорий:**
   - Убедитесь, что подкатегории имеют правильный `parent` ID

2. **Проверьте ACF поля:**
   - Убедитесь, что поля `category_image` и `category_background` заполнены

## Технические детали

### Используемая таксономия
- **Название:** `product_category`
- **Post Type:** `product` (кастомный, не WooCommerce)
- **Иерархическая:** Да

### Запрос товаров
Запрос настраивается через хук `pre_get_posts`:
- `post_type` = `'product'`
- `posts_per_page` = `12`
- `post_status` = `'publish'`
