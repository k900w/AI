# Инструкция по настройке темы TEX-K

## Шаг 1: Активация темы

1. Войдите в админ-панель WordPress
2. Перейдите в **Внешний вид → Темы**
3. Найдите тему "TEX-K" и нажмите **Активировать**

## Шаг 2: Установка плагинов

### Обязательные плагины:
- **Advanced Custom Fields (ACF) Pro** - для кастомных полей

### Опциональные плагины:
- **WooCommerce** - для корзины и оформления заказов
- **WPML** - для мультиязычности

## Шаг 3: Импорт ACF полей

1. Установите и активируйте ACF Pro
2. ACF автоматически загрузит JSON конфигурацию из папки `acf-json/`
3. Если поля не загрузились, перейдите в **Custom Fields → Tools → Import Field Groups**
4. Выберите файлы из папки `acf-json/` и импортируйте их

## Шаг 4: Настройка меню

1. Перейдите в **Внешний вид → Меню**
2. Создайте новое меню или используйте существующее
3. Добавьте пункты меню:
   - Про компанію
   - Агроблог
   - Контакти
   - Підтримка
   - Техніка (с подменю)
   - Запчастини
4. Назначьте меню в:
   - **Primary Menu** - главное меню в шапке
   - **Top Menu** - верхнее меню
   - **Footer Menu** - меню в подвале

## Шаг 5: Настройка главной страницы

1. Создайте новую страницу или используйте существующую
2. В настройках страницы выберите шаблон **Front Page**
3. Заполните ACF поля:
   - **Баннеры слайдера** - добавьте баннеры для главного слайдера
   - **Переваги** - добавьте преимущества компании
   - **О компании** - заполните информацию о компании
4. Установите эту страницу как главную: **Настройки → Чтение → Главная страница**

## Шаг 6: Импорт товаров из Битрикс

1. Откройте файл `import-bitrix-to-wp.php` в корне сайта
2. Настройте параметры подключения к БД Битрикс в начале файла:
   ```php
   $bitrix_db_host = 'localhost';
   $bitrix_db_name = 'bitrix_db';
   $bitrix_db_user = 'root';
   $bitrix_db_pass = '';
   ```
3. Откройте файл в браузере: `http://ваш-сайт.com/import-bitrix-to-wp.php`
4. Нажмите кнопку **Начать импорт**
5. Дождитесь завершения импорта

## Шаг 7: Копирование ресурсов

Убедитесь, что скопированы все ресурсы:

1. **Шрифты**: `tex-k.com.ua/local/templates/kdteam/fonts/` → `wp-content/themes/tex-k/assets/fonts/`
2. **Изображения**: `tex-k.com.ua/local/templates/kdteam/images/` → `wp-content/themes/tex-k/assets/images/`
3. **JavaScript**: `tex-k.com.ua/local/templates/kdteam/js/` → `wp-content/themes/tex-k/assets/js/`

## Шаг 8: Настройка категорий товаров

1. Перейдите в **Товары → Категории**
2. Создайте категории товаров
3. Для каждой категории заполните ACF поля:
   - **Зображення категорії** - изображение для отображения на главной
   - **Фонове зображення** - фоновое изображение блока
   - **Іконка категорії** - иконка категории

## Шаг 9: Добавление товаров

1. Перейдите в **Товары → Добавить новый**
2. Заполните основную информацию:
   - Название
   - Описание
   - Изображение товара
3. Заполните ACF поля:
   - **Ціна** - цена товара
   - **Валюта** - валюта (UAH/USD/EUR)
   - **Артикул** - артикул товара
   - **Характеристики** - характеристики товара
   - **Галерея** - дополнительные изображения
   - **Документи** - документы товара
4. Выберите категорию товара
5. Опубликуйте товар

## Шаг 10: Настройка виджетов

1. Перейдите в **Внешний вид → Виджеты**
2. Настройте виджеты для боковой панели (если используется)

## Проверка работы

После настройки проверьте:

1. ✅ Главная страница отображается корректно
2. ✅ Меню работает
3. ✅ Слайдер на главной работает
4. ✅ Категории товаров отображаются
5. ✅ Товары отображаются
6. ✅ Страница товара работает
7. ✅ Стили применяются корректно
8. ✅ Шрифты загружаются

## Решение проблем

### Стили не применяются
- Очистите кеш браузера
- Проверьте, что файлы CSS скопированы в `assets/css/`
- Проверьте пути к файлам в `functions.php`

### ACF поля не отображаются
- Убедитесь, что ACF Pro установлен и активирован
- Проверьте, что JSON файлы находятся в `acf-json/`
- Импортируйте поля вручную через ACF Tools

### Товары не импортируются
- Проверьте параметры подключения к БД Битрикс
- Убедитесь, что таблицы Битрикс существуют
- Проверьте права доступа к БД

### Изображения не отображаются
- Проверьте пути к изображениям
- Убедитесь, что файлы скопированы в `assets/images/`
- Проверьте права доступа к файлам

## Дополнительная настройка

### Настройка корзины (если используется WooCommerce)
1. Установите и активируйте WooCommerce
2. Настройте типы товаров
3. Интегрируйте с темой

### SEO настройка
1. Установите плагин Yoast SEO или Rank Math
2. Настройте мета-теги для товаров
3. Создайте XML карту сайта

### Кеширование
1. Установите плагин кеширования (WP Super Cache, W3 Total Cache)
2. Настройте кеширование
3. Очистите кеш после изменений
